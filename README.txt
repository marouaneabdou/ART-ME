ARTIST WEBSITE TEMPLATE

1. Open the folder "artist-website-template" in Visual Studio Code.
2. Open index.html in your browser, or use the Live Server extension in VS Code.
3. Replace the image links in index.html with links to your own artwork.
4. Update painting titles, media, dimensions, email address, and Instagram link.

Files:
- index.html : page content
- style.css  : design and responsive layout
- script.js  : artwork popup and navigation behaviour
